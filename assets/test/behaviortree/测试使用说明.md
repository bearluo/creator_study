# 行为树测试使用说明

## 📋 概述

本文档说明如何在 Cocos Creator 场景中运行行为树测试。

## 🚀 快速开始

### 1. 创建测试场景

1. 在 Cocos Creator 中创建一个新场景
2. 在场景中添加一个空节点
3. 将 `SceneBehaviortreeTest` 组件添加到该节点

### 2. 配置测试选项

在属性检查器中配置以下选项：

- **Run Basic Test**: 是否运行基础测试（默认：true）
- **Run ECS Integration Test**: 是否运行 ECS 集成测试（默认：true）
- **Auto Run**: 是否在 start 时自动运行测试（默认：true）
- **Test Delay**: 测试延迟时间（秒，默认：1）

### 3. 运行测试

#### 自动运行

如果 `Auto Run` 为 true，测试会在场景加载后自动运行。

#### 手动运行

在控制台或代码中调用：

```typescript
// 运行所有测试
sceneBehaviortreeTest.runTests();

// 只运行基础测试
sceneBehaviortreeTest.runBasicTests();

// 只运行 ECS 集成测试
sceneBehaviortreeTest.runECSIntegrationTests();
```

## 📝 测试内容

### 基础测试（BasicTest）

1. **testSimpleCondition**: 测试简单条件节点
2. **testSelector**: 测试选择器节点
3. **testSequence**: 测试序列节点
4. **testDecorator**: 测试装饰器节点（Inverter）
5. **testParallel**: 测试并行节点
6. **testRepeater**: 测试 Repeater 装饰器
7. **testUntilSuccess**: 测试 UntilSuccess 装饰器
8. **testUntilFailure**: 测试 UntilFailure 装饰器
9. **testComplexTree**: 测试复杂行为树

### ECS 集成测试（ECSIntegrationTest）

1. **testBasicIntegration**: 测试基本 ECS 集成
2. **testEntityDataBinding**: 测试 Entity 数据绑定（基础）
3. **testEntityDataBindingComplete**: 测试 Entity 数据绑定（完整功能）
4. **testMultipleEntities**: 测试多 Entity 并发
5. **testExecuteInterval**: 测试执行间隔控制

## 🔧 运行单个测试

```typescript
// 运行单个基础测试
sceneBehaviortreeTest.runSingleBasicTest('simpleCondition');
sceneBehaviortreeTest.runSingleBasicTest('selector');
sceneBehaviortreeTest.runSingleBasicTest('sequence');
sceneBehaviortreeTest.runSingleBasicTest('decorator');
sceneBehaviortreeTest.runSingleBasicTest('parallel');
sceneBehaviortreeTest.runSingleBasicTest('repeater');
sceneBehaviortreeTest.runSingleBasicTest('untilSuccess');
sceneBehaviortreeTest.runSingleBasicTest('untilFailure');
sceneBehaviortreeTest.runSingleBasicTest('complexTree');

// 运行单个 ECS 集成测试
sceneBehaviortreeTest.runSingleECSIntegrationTest('basicIntegration');
sceneBehaviortreeTest.runSingleECSIntegrationTest('entityDataBinding');
sceneBehaviortreeTest.runSingleECSIntegrationTest('entityDataBindingComplete');
sceneBehaviortreeTest.runSingleECSIntegrationTest('multipleEntities');
sceneBehaviortreeTest.runSingleECSIntegrationTest('executeInterval');
```

## 📊 查看测试结果

测试结果会输出到 Cocos Creator 的控制台：

- ✅ 成功：测试通过
- ❌ 失败：测试失败（会显示错误信息）
- 📝 日志：详细的执行日志

## ⚠️ 注意事项

1. **ECS 测试**: ECS 集成测试需要确保 ECS 系统已正确初始化
2. **执行间隔**: 某些测试涉及时间控制，可能需要等待
3. **控制台输出**: 确保控制台窗口可见以查看测试结果
4. **测试顺序**: 测试会按顺序执行，某些测试可能依赖前面的结果
5. **API 使用**: 
   - 使用 `world.registerSystem(BehaviorTreeSystem)` 注册系统
   - 使用 `btComponent.updateInterval` 设置更新间隔
   - 使用 `btComponent.behaviorTree?.getStatus()` 获取状态

## 🐛 调试

如果测试失败：

1. 检查控制台错误信息
2. 确认所有依赖已正确导入
3. 检查 ECS 系统是否正确初始化
4. 查看详细的日志输出

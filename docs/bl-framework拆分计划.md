# bl-framework 拆分计划

## 项目概述

**目标**: 将 bl-framework 核心代码拆分为多个独立的 npm 库，提高模块化和可维护性。

**当前状态**: bl-framework 是一个 Cocos Creator 扩展包，包含多个模块。

**第一步**: 整理核心 core 库

## 当前结构分析

### 模块列表
- `behaviortree/` - 行为树系统
- `common/` - 通用工具
- `declare/` - 类型声明
- `ecs/` - ECS 框架
- `events/` - 事件系统
- `extensions/` - 扩展功能
- `hotupdate/` - 热更新
- `manager/` - 管理器
- `network/` - 网络模块
- `ui/` - UI 组件

### 依赖关系分析

需要进一步分析各模块之间的依赖关系，确定核心代码范围。

## Core 库规划

### 核心库应该包含

1. **基础类型和接口**
   - 类型定义
   - 基础接口

2. **通用工具**
   - 工具函数
   - 辅助类

3. **事件系统**（如果独立）
   - 事件管理器
   - 事件类型

4. **基础框架**（如果独立）
   - 基础类
   - 核心抽象

### 核心库不应该包含

- Cocos Creator 特定功能
- 业务逻辑
- UI 组件
- 网络请求
- 管理器（业务层）

# 项目简介

## 项目概述
bl-framework-demo 是一个基于 Cocos Creator 3.8.4 的游戏开发框架，提供丰富的功能模块和工具集。

## 核心框架
- **bl-framework**: 核心框架扩展
  - ECS 系统（Entity-Component-System）
  - 管理器系统（Manager System）
  - UI 系统
  - 网络模块
  - 热更新系统
  - 事件系统

## 项目结构
- `extensions/bl-framework/`: 核心框架代码
- `assets/test/`: 测试和示例代码
- `docs/`: 项目文档

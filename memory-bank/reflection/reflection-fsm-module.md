### 挑战与解决

**挑战 1**: 状态转换的查找效率
- **问题**: 需要快速查找从当前状态出发的转换
- **解决**: 使用 Map 存储转换规则（event -> TransitionConfig[]），O(1) 查找

**挑战 2**: 生命周期钩子的执行顺序
- **问题**: 确保钩子按正确顺序执行
- **解决**: 明确执行顺序：onExit -> onTransition -> onEnter

**挑战 3**: 状态历史的长度限制
- **问题**: 防止历史记录无限增长
- **解决**: 使用 maxHistoryLength 限制，超出时自动移除最旧记录

**挑战 4**: 构建器模式的链式调用
- **问题**: 确保所有方法返回 this
- **解决**: 所有方法都返回 this，支持链式调用
